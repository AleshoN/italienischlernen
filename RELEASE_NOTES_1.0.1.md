# Piano 1.0.1 – GitHub-Pages-Veröffentlichung

Piano 1.0.1 stellt die vollständige A0-Lernplattform dauerhaft als öffentliche GitHub-Pages-Web-App bereit.

Die Anwendung wird nach jeder freigegebenen Änderung auf `main` automatisch getestet, für den Repository-Unterpfad gebaut und auf derselben Adresse neu veröffentlicht. PWA-Manifest, Service Worker, Offline-Start, Appsymbol, Programmdateien und das offene Wörterbuch funktionieren sowohl lokal als auch unter GitHub Pages.

Der Lerninhalt bleibt unverändert auf Version 1.0.0: 13 Module, 84 Lerneinheiten, 168 Übungen, 13 Modultests, eine zwölfteilige A0-Abschlussprüfung, 747 kuratierte Kurswörter und -wendungen sowie 16.707 offene Wörterbuchformen. Datenschema 6 und alle dauerhaften IDs bleiben kompatibel.

Persönliche Fortschritte liegen weiterhin ausschließlich im jeweiligen Browserprofil. Vor einem Browser- oder Gerätewechsel empfiehlt sich eine Sicherung im Bereich **Daten**.

Die öffentliche App ist unter `https://aleshon.github.io/italienischlernen/` erreichbar. Start und bekannte Einschränkungen stehen in `README.md`, die tatsächlich ausgeführten Prüfungen in `TESTS.md`.
